# YAMLERD
This is a Streamlit in Snowflake App that enables a user to produce and explore an ERD against a Snowflake Semantic Model YAML file 



### How to Deploy (Alternatively download the files if you don't want to connect to Git) 
1) In Snowsight, click on projects then streamlit
2) In the upper right corner click the blue button to create a Streamlit app
3) Name it whatever you want and use any db, schema, and wh you want
4) In the editor, copy paste the provided python code then run the app
